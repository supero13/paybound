# Paybound demo video script

Final cut: `demo/paybound-demo.mp4`, about 177s (2:57), 1920×1080, 30 fps. Phone frames (430×932 captures) are shown inside a 16:9 layout. Scenes are joined with 0.4s crossfades (no black frames). Narration is never sped up or resampled for timing; each scene is as long as its narration plus padding. Respellings like “pay-ee” and the word “suggests” (instead of “drafts”) are deliberate, to fix Piper's pronunciation.

- **Voiceover:** [Piper](https://github.com/rhasspy/piper), an offline neural TTS, with voice `en_US-ryan-high`.
- **Capture:** headless Chrome against the live site `https://paybound-qday.netlify.app` (`demo/capture.mjs`). It uses a read-only stand-in wallet for the deployer address that answers account/chain requests, forwards reads to the public RPC, and refuses every signing request. Netlify's “Powered by Netlify” badge script is blocked in captures only. Each frame's page text is checked so it can't contain any private key or LLM key.
- **Real on-chain moment:** the Ask draft for “send the smoke payee five cents for testing” (parsed by Groq `openai/gpt-oss-120b`) was signed from the deployer wallet via `cast` using the draft's own `ref`, memo and amount: [`0x28dba4e6a8556e964cf3e6e975c584be2164ab0c64121808d1b8ab1e6a71d74f`](https://explorer-test.qday.info/tx/0x28dba4e6a8556e964cf3e6e975c584be2164ab0c64121808d1b8ab1e6a71d74f).
- **Rebuild:** `python3 demo/build.py` (needs Piper and ffmpeg). Scene text lives in `demo/scenes.py`.
